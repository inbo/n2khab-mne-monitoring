### usernames are wrong
In #TeamMembers, I was convinced that the `username` field is "small letters" and without spaces.
It turns out that this is not the case: some names have trailing spaces, and names are capitalized.

Worse even: 
- Trailing spaces are present in all database [[locations/structure sheets|structure sheets]], and in the actual table only on #mnmsyncdb.
- Trailing spaces did not occur on the newer colleagues' entries.
- This caused inconsistencies with the #FreeFieldNotes

Solution: `LOWER(TRIM(username))` in all structure sheets (for consistency).

```sql
UPDATE "metadata"."TeamMembers"
SET username = LOWER(TRIM(username));
```

### duplicate #FreeFieldNotes

`log_creator` and `log_creation` are treated as [[tooling/characteristic columns|characteristic]] for #FreeFieldNotes.
However, occasionally the asynchronous storage method of QGIS produces identical timestamps for different entries (reason: they only INSERT upon manual saving).

```sql
SELECT DISTINCT
  log_creator,
  log_creation,
  count(*) AS n
FROM "inbound"."FreeFieldNotes"
GROUP BY
  log_creator,
  log_creation
HAVING count(*) > 1
;

```

This time one pair of FFN by #WT induced a warning.

```sql
SELECT * FROM "inbound"."FreeFieldNotes" WHERE log_creation = '2026-11-16 13:15:01.213';

UPDATE "inbound"."FreeFieldNotes"
SET log_creation = '2026-11-17 13:15:01.213', teammember_id = 7
WHERE log_creation = '2026-11-16 13:15:01.213'
AND note_date = '2026-11-17'
;

```
