#### remove obsolete notes column

#FieldCalendars notes were moved to #Visits during [[structure/implement optional and intrinsic matching occasions in all databases|implement optional and intrinsic matching occasions in all databases]] 

+ double checked content of these columns: all deviations are okay
```sql
\COPY (
 SELECT DISTINCT
  CAL.visit_id,
  CAL.notes,
  VIS.preparation_notes
FROM "outbound"."FieldCalendars" CAL
LEFT JOIN "inbound"."Visits" VIS
  ON VIS.visit_id = CAL.visit_id
WHERE NOT (CAL.notes = VIS.preparation_notes)
) TO '20261126_checknotes.csv' With CSV DELIMITER ',' HEADER
;
```
