The issue by the SAMPLPOINT activities was solved by filtering them explicitly:
```sql
  AND (ACT.activity_group NOT LIKE '%SAMPLPOINT')
```

## follow-up #LocevalInfos

There is a view in #mnmgwdb and #mnmsurfdb which aggregates the data from #LocationEvaluations.

That source table, however, defines which columns transfer.
To add `activity_group`, it must be appended as a column.

```sql

ALTER TABLE "transfer"."LocationEvaluations" ADD COLUMN activity_group varchar; 
COMMENT ON COLUMN "transfer"."LocationEvaluations".activity_group IS E'label for a group of activities, can be `ORTHOPHOTOEVAL`';

```
