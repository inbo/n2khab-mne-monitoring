A scheme (*nl: meetnet*) in context of the #MNE [[glossary/revisit plan|REP]] is a single monitoring network (i.e. combination of environmental pressure and ecological compartment).

For example, currently active schemes are

+ `GW_03.3` = grondwatermeetnet: eutrofiëring via grondwater
+ `SURF_03.4_lentic` = oppervlaktewatermeetnet: eutrofiëring via oppervlaktewater, deel *stilstaande* wateren
+ `SURF_03.4_lotic` = oppervlaktewatermeetnet: eutrofiëring via oppervlaktewater, deel *stromende* wateren
