This folder contains instructions on how to interact with the database from various systems (QGIS, terminal, code, ...).

In general, our database are open for access through any software that can handle SQL connections.
Often used examples are: 
+ the command line: [[usage/psql cli]]
+ [`dbeaver`](https://dbeaver.io) or other SQL management "studio" programs
+ [[R/R|R]], best via the [[R/MNMDatabaseConnection|MNMDatabaseConnection]] (see [[R/R database connection usage example|R database connection usage example]])
+ [[usage/python|python]]
+ [[usage/qgis|qgis]] and [[usage/qfield|qfield]]
+ ...
