*An overview of the structure and features of tables we maintain in our databases.*

Not all tables are covered here in all detail. 
Database structure and content evolve at swift pace, and it would be futile to try to mirror all components in this documentation.
If up-to-date exact [[database/structure|structure]] is critical, please refer to the overview provided by the [[database/generation|structure sheets]].

However, on some occasions, e.g. when considerable work was put on the integration of a certain table, we will maintain an overview of the intentions and constraints in this folder.
